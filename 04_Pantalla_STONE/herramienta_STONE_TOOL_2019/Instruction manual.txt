	If the virtual serial screen function and serial debugging assistant in the VGUS4.3 development tool cannot be used, please try the following three methods in order:
1. Please right click and select to run the "Register.cmd" program as an administrator;
2. If the first method is successful, the second method is not needed; if the first method is still not working, please follow the steps below to complete the second method:
1 computer is a 32-bit operating system, please manually copy the mscomm32.ocx control to the c:\windows\system32 folder, and then right-click to run the "register.cmd" program as an administrator;
2 The computer is a 64-bit operating system. Please manually copy the mscomm32.ocx control to the c:\windows\SysWOW64 folder, and then right-click to run the "Register.cmd" program as an administrator.
3. If the second method is successful, the third method is not needed; if you still can't use the second method, please follow the steps below to complete the third method:
	On the basis of the completion of the second method, find the cmd.exe file in the c:\windows\system32 folder of the 32-bit operating system, right click--run as administrator (key)--enter regsvr32 MSCOMM32.OCX The problem is solved; find the cmd.exe file in the c:\windows\SysWOW64 folder on the 64-bit operating system, right click--run as administrator (key)--enter regsvr32 MSCOMM32.OCX, the problem can be solved.
	The first and second methods are successful under some systems, and the third method is successful under all systems.
